**How to read this plan.** `qa` never fixes component code and never edits other plans: findings go to
`docs/testing/reports/<date>-qa-<n>.md`. Tasks are ordered by dependency; `⚑` = critical path for the M1 release
check. `tests/` has its own `package.json` (it is not a root workspace) — commands run as `npm --prefix tests run
<script>`. Everything here runs against `relay-server` + `fake-slicer` + `web-viewer` built from `main`; device
and Slicer scenarios are manual and live in `docs/testing/<component>.md`.
