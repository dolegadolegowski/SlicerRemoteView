**How to read this plan.** All `QST-` tasks belong to **M3b**. **M3a (Quest WebXR) has no `QST-` tasks**: it is
delivered by the `web` workstream as `WEB-19` (WebXR mode) and `WEB-20` (XR grab/rotate/scale), verified by
`QA-11`; this plan starts only after those are `done` and `PRO-17` (C# DTOs) is on `main`. `⚑` marks the M3b
critical path. Unity and Android tooling are not in the sandbox: protocol logic lives in a `UnityEngine`-free
assembly tested with EditMode tests (and `dotnet test quest-app/Tests.NET` when `dotnet` exists); everything
on-device is a manual step in `docs/testing/quest.md` (numbered sections below).
