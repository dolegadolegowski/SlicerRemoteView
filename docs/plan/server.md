**How to read this plan.** Tasks are ordered by dependency; `⚑` = critical path (`docs/plan/00-overview.md` §4).
Dependencies on `PRO-` tasks may be stubbed locally when `ws/protocol` is not yet on `main` (`[stub allowed]`,
record `[stub: PRO-xx]`); the stub must be replaced by the workspace import before the milestone closes.
Every task ships with its vitest tests; timers are injectable (fake clock) so TTL logic is unit-testable.
