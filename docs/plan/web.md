**How to read this plan.** Tasks are ordered by dependency; `⚑` = critical path (`docs/plan/00-overview.md` §4).
`src/protocol/` (connection, reassembly, versions) has no DOM or three.js imports and is unit-tested on fixtures
from `shared/`; `src/render/` wraps three.js; `src/ui/` is DOM. Until `relay-server` is on `main`, E2E runs
against the `fake-slicer` relay stub (`PRO-13`) — mark `[stub: SRV-xx]`. iOS Safari behaviour is verified on a
device per `docs/testing/web.md`; Playwright WebKit is not Safari.
