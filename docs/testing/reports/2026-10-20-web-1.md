# Threat model T6 and US-07 promise that `history.replaceState` removes the code from browser history; it cannot

- **Reported by**: web (`ws/web`, commit `6ba13ae` + WEB-11)
- **Affects**: release — `docs/architecture.md` §8 threat T6, `docs/requirements.md` US-07 (and NFR-15 wording),
  `docs/research/web.md` §4 (research note, via the architect)
- **Severity**: medium (documentation of a residual privacy risk; no code change can fix it)
- **Milestone**: M2
- **Protocol**: v1.0 §10 (`GET /j`, code only in the fragment)
- **Status**: open

## Steps to reproduce

1. In Chromium (Android Chrome's engine) with a persistent profile, open `https://<host>/j#<CODE>` (a QR scan does
   the same: a new page with the fragment).
2. The viewer calls `history.replaceState(null, '', '/j')` before any network call (WEB-11): the address bar, the
   tab's Back/Forward entries and the tab overview show `/j`.
3. Open the browser's History list (`chrome://history`) or the profile's `History` database.

## Expected (as documented)

T6: "`history.replaceState` removes it" (the code, from browser history). US-07: "when I look at the address bar or
history, then the code has been removed (`/j`)". research web.md §4: "remove the code from the address bar/history
… so screenshots, shared tabs and history do not leak it".

## Actual

The History list (and address-bar suggestions, and history sync if enabled) contains a visible visit to
`/j#<CODE>` next to the rewritten `/j`. The browser records the URL it navigated to when the page commits, before
any script runs; `replaceState` only rewrites the session-history entry. No web API can delete that visit. WebKit
(Safari) very likely behaves the same `[TODO verify]` on a device (`docs/testing/web.md` §Deep link step 2 records it).

## Notes / suspected cause

Not a defect of the viewer code — a limit of the web platform. Suggested: T6 and US-07 say "address bar and the
tab's session history (Back/Forward, tab overview, shared tabs, screenshots)" and add the global History list as a
residual risk, bounded by the code's TTL/expiry and the session's end (ADR 0008); optionally a user-guide hint to
use a private tab on shared devices.
