## Please change

1. **T11 / `session.publisherState` (report 2026-10-18-server-7).** Decided: **no** `sessionId` field. Narrow the T11
   wording to what the message carries (`online`, `graceEndsAt`), and change architecture §3 so that a just-ended code
   answers `INVALID_CODE`.
2. **T5 (report 2026-10-20-slicer-1; decision D5 = no protocol text).** Add to T5 *Residual risk*: "an institution's
   TLS-inspecting proxy whose root CA is in the Windows store can read the session (the UI and the user guide recommend
   exempting the relay host); Slicer's bundled OpenSSL 1.1.1 is end of life — connect only to the configured relay
   host (the transport refuses redirects)". Fix `docs/research/slicer.md` (per-OS trust, `slicer-transport.md` §2).
3. **`TRUST_PROXY` (report 2026-10-18-server-1).** Architecture §9 and ADR 0008 §6a say `trustProxy: true`, which in
   Fastify trusts every hop; the relay trusts exactly one (the last `X-Forwarded-For` entry). Add the erratum. The
   hop count is measured by DEP-06 (the owner confirmed the first deploy is planned).
4. **Heartbeat (FR-21, NFR-21; decision accepted).** The relay's WS-ping liveness also counts publisher frames and a
   draining send buffer (≤ 60 s without echo, frame or draining); a client detects a dead downlink by its own `pong`
   timeout. Amend FR-21 (tagged non-negotiable — the owner accepted the change), NFR-21 ("≤ 25 s to detect a dead
   connection" holds for idle connections; a publisher uploading a snapshot may take up to 70 s, §9.1) and ADR 0009
   Decision 4 (publisher `pong` deadline `10 s + min(60 s, B / 125,000 B/s)`).
5. **Transforms and ids.** ADR 0005 errata and architecture §6.4: `baked` also covers shear and degenerate scales
   (TRS-only, §7.2); segment `nodeId` aliases `<segNodeID>/s_<n>` for non-conforming IDs and for all segments when names
   are anonymised (§7.3).
6. **Registry and sessions.** Architecture §2.9/§3: ended viewer-token hashes are kept for `CODE_QUARANTINE_S`
   (bounded) only to answer `410`; the per-viewer last `scene.request` answer time replaces the counter
   `sceneRequests`; the code goes into quarantine on `session.close` (§4.5).
7. **Serving the viewer (report 2026-10-20-server-7).** Record the CSP (ADR 0006 §4, `worker-src 'self' blob:`) in
   the architecture or point §T6 to it; QA-05: `/j?code=X` is `200` with the body of `/j`, not `404`; `deploy`: serve the
   relay on a dedicated host name (HSTS `includeSubDomains`).
8. **Plans.** Mark `[protocol change: v1.1]` in the slicer, server, web and quest plans (see reports
   2026-10-27-protocol-1…3) and add PRO-20…PRO-24 to the overview's protocol chain. `PROTOCOL_VERSION` becomes `"1.1"`
   with PRO-22.
