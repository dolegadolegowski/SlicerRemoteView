# SlicerRemoteView — instrukcja użytkownika / user guide

## Polski

SlicerRemoteView pokazuje scenę 3D z 3D Slicera na telefonach, tabletach i goglach Meta Quest.
Moduł RemoteView wysyła scenę przez serwer pośredniczący (relay), a urządzenia dołączają 5-znakowym kodem
albo kodem QR.

1. [Ręczna instalacja pluginu RemoteView w 3D Slicerze](pl/install-plugin.md)
2. [Własny serwer do połączeń zdalnych](pl/own-server.md) — pomiń, jeśli ktoś poda Ci adres serwera.

Dla właściciela repozytorium: osoby zapraszasz w repozytorium przez **Settings** → **Collaborators** →
**Add people**; potrzebna jest ich nazwa użytkownika GitHuba.

## English

SlicerRemoteView shows the 3D scene of 3D Slicer on phones, tablets and Meta Quest headsets.
The RemoteView module sends the scene through a relay server, and the devices join with a 5-character code
or a QR code.

1. [Install the RemoteView plugin in 3D Slicer manually](en/install-plugin.md)
2. [Run your own server for remote connections](en/own-server.md) — skip this if someone gives you a server address.

For the repository owner: invite people in the repository's **Settings** → **Collaborators** →
**Add people**; you need their GitHub user name.
